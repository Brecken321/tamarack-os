# Tamarack OS

**Your PC, your rules. No ads, ready to play.**

Tamarack OS is a desktop operating system for gaming PCs and everyday use. It is a custom
[bootc](https://bootc-dev.github.io/) image built on [Bazzite](https://bazzite.gg/) and
[Universal Blue](https://universal-blue.org/), which are based on Fedora Linux with the KDE Plasma desktop.

> Status: early development. See [ROADMAP.md](ROADMAP.md) and [TESTING.md](TESTING.md) for what is built and
> what has been verified. Tamarack OS is not affiliated with or endorsed by Bazzite, Universal Blue, Fedora, KDE,
> Valve or Microsoft.

Full documentation is being written in this repository.
